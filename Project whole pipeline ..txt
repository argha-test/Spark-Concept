The implementation was done by copy activity of ADF. First we used get meta data activity to fetch all child item in the container. Then we applied filtering logic to ensure get only specific file pattern .After that we used foreach activity to control the iteration , inside for loop activity we used get mata data activity to find out last modified date and finally trigger the copy activity to movement the raw data.This is the all bronze level setup.

In my recent project, I built an end-to-end Azure data pipeline where client files were dropped into Azure SFTP in flat file system and ingested into ADLS using Azure Data Factory. We organized data in a Bronze layer using a date-based folder structure also ensure  date should be last modified date of file and dynamic file naming like append with current dateTime to ensure uniqueness and avoid duplicates. Then, using Databricks with PySpark, we transformed the data into a Silver layer by adding housekeeping columns like SourceFile and ReportDateTime. Finally, the processed data was ingested into Azure Data Explorer for reporting. We also implemented secure access using Service Principal and Azure Key Vault.”
