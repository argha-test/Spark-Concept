3. Incremental Load with Databricks Merge with DeltaLake (Merge(upsert))
Ans: Update existing records + Insert new records in one operation
     create a first target table first
     MERGE INTO target t
     USING source s
     ON t.id = s.id

     WHEN MATCHED THEN
       UPDATE SET t.salary = s.salary

     WHEN NOT MATCHED THEN
      INSERT (id, name, salary)
      VALUES (s.id, s.name, s.salary)
	  
	 I design incremental pipelines using a watermark column like created_date or updated_date, or sometimes change data capture if available. I store the last successful processed value in a metadata table, then read only new or changed records. In Delta Lake, I use MERGE INTO for insert/update logic so I don’t reload the full dataset every time. This makes the pipeline faster, cheaper, and easier to recover.
